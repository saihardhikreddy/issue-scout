🔭 Issue Scout live demo

★ View on GitHub

Find fresh, unclaimed GitHub issues in projects whose AI-contribution policy fits you. This page runs entirely in your browser against the public GitHub API.

Optional: GitHub token for higher rate limits Without a token GitHub allows about 10 searches a minute. A token with no scopes raises that a lot. It is kept in this page's memory only and sent only to api.github.com.

This demo is a lighter version of the CLI: it checks linked PRs, assignees and each project's AI_POLICY.md / CONTRIBUTING files, but not every cross-referenced PR. For the full search with ranking across up to 60 projects, install the CLI: pip install git+https://github.com/saihardhikreddy/issue-scout. Policy verdicts come from keyword rules, so read the project's guidelines before starting.
